# Clade 0.2.0 — Native Codex Support

[中文说明](#中文说明)

Clade 0.2.0 adds first-class Codex support while keeping existing Claude Code
and MCP installations backward compatible.

## Highlights

- Native Codex plugin with 20 generated core workflows
- Codex lifecycle hooks for session context and destructive-command protection
- Provider-neutral `clade-mcp` runtime with Claude, Codex, and conservative
  automatic selection
- 32 workflows in the MCP package, up from 29 in 0.1.0
- Configurable Codex sandbox with an explicit, opt-in permission bypass
- Deterministic generation and CI drift checks for the Codex plugin
- Complete English and Chinese documentation for Codex and MCP setup

## Install or upgrade

Install the native Codex plugin:

```bash
codex plugin marketplace add shenxingy/Clade
codex plugin add clade@clade
```

Upgrade the MCP package:

```bash
pip install --upgrade clade-mcp
```

Existing MCP users continue to use the Claude runtime by default. To execute
through Codex from an external MCP client, set `CLADE_RUNTIME=codex`. Native
Codex users should use the plugin directly instead of mounting `clade-mcp`
inside Codex.

See the [Codex guide](../codex.md),
[MCP guide](../../mcp-package/README.md), and
[changelog](../../CHANGELOG.md) for details.
