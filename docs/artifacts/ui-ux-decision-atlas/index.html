世界第一，不存在。

存在的是：在特定用户、平台、任务和指标下，证据最强的方案。先定义“赢什么”，再找参考。

The useful answer 不要找一个冠军。建立一套证据梯度。

奖项告诉你行业审美；平台规范告诉你用户预期；可用性测试告诉你能不能用；线上数据才告诉你是否真的更好。

01 / Evidence ladder

“最好”必须分层判断

同一张漂亮截图，可能拿奖，却无法完成任务。五层证据回答五个不同问题，越往下越接近真实产品价值。

点击左侧层级，查看它能证明什么，以及最常见的误用。

01

它是否有视觉与叙事突破？

Awwwards、FWA、Webby、Apple Design Awards 适合发现优秀表达与新模式；它们不是任务成功率、学习成本或商业结果的排行榜。

最适合灵感、视觉语言、品牌表达、动效方向
不要推断拿奖 = 最好用；高票 = 适合你的用户
奖项是品味样本，不是真理。平台规范是默认答案，也不是产品策略。

一项设计的最终证据链应该能从“为什么看它”，一路走到“用户是否更快、更准、更少犯错，以及业务是否改善”。任何中间层都不能代替最后一层。

03 / Native × custom

苹果原生，还是自己造？

答案不是二选一。最稳的产品通常有三层：平台契约保持原生，产品工作流做出自己的大脑，品牌表达形成自己的气质。

Working model

原生骨架。产品大脑。品牌气质。

越接近输入、无障碍、键盘、窗口和系统行为，越应服从平台；越接近任务模型与独特价值，越应该自研。

平台契约

01 / KEEP NATIVE

这是用户已经学会的语言。擅自重写会增加学习成本，并经常破坏无障碍与系统集成。

  • 语义与焦点
  • 键盘与快捷键
  • 菜单与窗口
  • 文本选择与拖放
  • 动态字体
  • 减少动态效果

产品大脑

02 / INVENT HERE

这才是产品需要赢的地方：用户如何理解任务、推进工作、恢复错误，以及在复杂状态中保持方向感。

  • 信息架构
  • 核心工作流
  • 空、错、加载状态
  • 批量操作与撤销
  • AI 等待与不确定性
  • 产品级快捷方式

品牌气质

03 / EXPRESS

在不破坏前两层的前提下，让产品被记住。品牌不是给每个按钮加特效，而是持续一致的表达系统。

  • 颜色与字体
  • 版式与密度
  • 图形与插画
  • 数据可视化
  • 声音与触觉
  • 标志性动效

macOS

SwiftUI + AppKit + HIG

窗口、菜单栏、快捷键、焦点、拖放与标准指针尽量原生；工作流、信息架构和品牌表达可以定制。原生按钮保留箭头光标是正常平台行为。

Windows

WinUI 3 + Fluent 2

沿用系统控件状态、键盘导航、窗口行为与输入模型；用产品自己的任务层组合它们。WinUI 3 Gallery 是比截图更有价值的可运行目录。

Web

Semantic HTML + browser conventions

先尊重链接、按钮、表单、滚动和历史记录等浏览器语义。不要假装成 Mac 窗口；跨平台应共享产品逻辑和品牌，再翻译成各平台组件。

04 / Cursor + component states

光标不是装饰，是语义

苹果按钮上仍是箭头，不代表它落后；网页链接用手型，也不代表所有可点击元素都必须手型。平台习惯与组件语义优先。

把鼠标移到右侧样本上，观察光标与说明。

Cursor rule

不要只靠光标告诉用户“这里能点”。

可点击性应同时来自文案、位置、形状、反馈与焦点。光标只是补充信号，而且触屏根本没有 hover。

05 / Purposeful motion

哪些地方真的需要动画

动效只在五种情况下有明确工作：确认反馈、解释空间关系、维持对象连续性、引导注意、表达进度。没有任务，就没有动画。

Motion test

删掉动画后，用户是否更难理解发生了什么？

如果答案是否，它很可能只是装饰。高频操作尤其要克制；退出通常比进入更短；任何体验都必须尊重 reduced motion。

07 / Sensible defaults

没时间研究时，先用这些默认值

默认值不是永恒真理，而是成本最低、最不容易伤害用户的起点。遇到证据，再覆盖它。

01

原生骨架，定制任务层

平台输入、焦点、快捷键、窗口与无障碍保持原生；信息架构、工作流和品牌表达由产品负责。

02

状态完整

特别是 keyboard focus、pressed、loading 与错误恢复。

03

Hover 不承载必要信息

触屏没有 hover；悬浮内容还必须可关闭、可停留、可聚焦。

04

目标够大

桌面至少满足 WCAG 2.2 的 24×24 CSS px 或间距例外；触摸优先瞄准 44×44。

05

动效有任务

确认、解释、连续性、注意、进度。其余从零开始论证。

最好的设计，不是最酷的状态。是最清楚的决定。
